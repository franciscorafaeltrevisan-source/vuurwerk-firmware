# Airband Soft Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Reduce harsh/treble-heavy speaker audio when receiving aviation AM without changing normal FM/USB audio.

**Architecture:** Extend `RADIO_SetModulation()` in `radio.c`. When modulation is AM and the active RX frequency is 118.00000–137.00000 MHz, program BK4819 REG 0x2B to `0x0400` (300 Hz HPF off, 3 kHz LPF on, de-emphasis on). For every other modulation/frequency, explicitly restore REG 0x2B to `0x0000` so the profile cannot leak into FM/USB.

**Tech Stack:** C, DP32G030/BK4819, VUURWERK build system, GitHub Actions.

**Spec:** Conversation-approved AIR SOFT profile, 2026-11-02.

## Global Constraints
- Preserve FM Broadcast on F+0.
- Preserve Fox Hunt on F+5, including direct frequency entry.
- Preserve AM Fix, RSSI bar and USB TX.
- AIR SOFT must affect only AM RX from 118.00000 through 137.00000 MHz inclusive.
- Restore normal audio register value outside that condition.

## Review Focus
- Boundary frequencies 118.00000 and 137.00000 MHz must enable AIR SOFT.
- 117.99999 and 137.00001 MHz must not enable AIR SOFT.
- FM on an airband frequency must not enable AIR SOFT.
- USB must restore normal audio profile.
- Switching from airband AM back to FM must clear REG 0x2B.
